# 羽毛球对阵图编辑器 (badmintonCanvas)

纯前端 Web 应用，用来制作羽毛球赛事赛果对阵图，并导出 PNG 海报。

## 启动

```bash
npm install
npm run dev      # 开发，打开终端里提示的地址
npm test         # 运行测试
npm run build    # 类型检查 + 打包
```

## 在线使用

<https://imqdcn.github.io/badmintonCanvas/>

推送到 `main` 分支会通过 GitHub Actions 自动测试、打包并重新部署（见 `.github/workflows/deploy.yml`）。

## 怎么用

- **模式**：左侧面板切换 男单 / 女单 / 男双 / 女双 / 混双。每种模式的对阵数据独立保存。
- **规模**：8 / 16 / 32 / 64 强。切换会清空当前模式的对阵（有数据时会先确认）。
- **选手**：点击对阵图里的位置，弹窗里搜索（中文、拼音、首字母、英文）。
  - 默认只列当前模式的名单，切到“全部”可搜索其他四份名单。
  - 双打模式下可“手动组合双打”（从单打名单各挑一位）。
  - 名单里没有的选手用“新增选手/组合”，保存在浏览器本地。
- **晋级**：只有首轮（如 32 强）可以从名单里选人。16 强及以后的位置只能是上一轮这场比赛的两位选手之一：
  悬停在首轮位置上点 ▶，或点击后面轮次的位置，在弹窗里“选择这场比赛的晋级者”，可以随时改选另一位。
  “撤销晋级”会清空该位置。改了首轮已晋级的选手，后续轮次里的同一个人会被自动清除，并在左侧提示。
- **比分/备注/种子/轮空**：在弹窗里填写。种子在首轮设置，晋级后自动带到后面的轮次。比分显示在“该场比赛的获胜位置”下方（下一轮的位置）。
- **分区标签**（1/4区…）：直接点击文字修改。
- **头部**：左侧面板可换海报（可缩放、移动）、Logo、标题、高亮关键词、日期、社交图标、水印。
- **导出**：左侧面板底部选 1x/2x/3x，点“导出 PNG”。编辑用的按钮、轮廓线不会出现在图片里。
- 所有内容自动保存在浏览器 localStorage，刷新不丢。

## 目录说明（给不熟悉 React 的你）

```
src/
  domain/          纯 TypeScript，和 React 无关，可单独测试
    types.ts       数据类型（模式、选手、位置、对阵图）
    bracket.ts     对阵图的创建、修改、晋级、连带清除
    layout.ts      每个位置的像素坐标（还原效果图的核心）
    roster.ts      把 BWF 源 JSON 解析成统一格式
    rosterImport.ts  名单 JSON 的导入校验 / 导出（两种格式）
    search.ts      名单搜索（含拼音）
    countries.ts   国家代码 -> 国旗/中文名
  providers/
    PlayerProvider.ts   名单数据源接口 + 内置 JSON 实现（导入的名单优先）
  data/            5 份名单 JSON（BWF 2026 年第 45 周前 100 名）
  store.ts         Zustand 全局状态 + localStorage 持久化
  components/
    Header.tsx         海报头部
    Bracket.tsx        对阵图（绝对定位 + SVG 连线）
    SlotEditor.tsx     点击位置后的编辑弹窗
    ControlPanel.tsx   左侧控制面板
    RosterPanel.tsx    名单导入 / 导出 / 恢复内置
  export.ts        导出 PNG（html-to-image）
  styles.css
```

学习提示：

- 组件 = 返回界面的函数；`useStore(s => ...)` 读取全局状态，状态变了组件自动刷新。
- 对阵图数据是二维数组 `slots[轮][位置]`，第 0 轮是首轮，最后一轮只有 1 个位置（冠军）。
  下一轮第 `i` 个位置由上一轮第 `2i`、`2i+1` 两个位置产生。
- 想改外观先看 `styles.css`，想改逻辑先看 `domain/`。

## 更新名单

有两种方式，使用同一种 JSON 格式（和 `src/data/` 里的内置名单一样）：

**A. 网页里导入 JSON（只对当前浏览器生效）**

左侧面板“名单”区域：先切到要更新的模式（男单 / 女单 / 男双 / 女双 / 混双），点“导入 JSON”选择文件，
文件会导入到**当前选中的模式**。导入成功后，下拉列表里该模式使用你导入的名单；“恢复内置名单”可以回到默认。
有任何一条数据不合格，会整体拒绝并列出问题（第几行、缺什么），不会导入一半。
点“导出当前名单”可以得到一份同样格式的文件，改完再导入即可。

**B. 改代码重新部署（所有访问者都生效）**

把新的 JSON 覆盖 `src/data/` 里的同名文件（`mens-singles.json`、`womens-singles.json`、`mens-doubles.json`、
`womens-doubles.json`、`mixed-doubles.json`），提交并推送到 `main`，GitHub Actions 会自动重新部署。

### 名单 JSON 格式

文件是一个数组，一行一条。

**单打（男单 / 女单）**

```json
[
  { "排名": 1, "所属": "FRA", "球员": "克里斯托·波波夫", "英文名": "Christo POPOV" },
  { "排名": 2, "所属": "THA", "球员": "昆拉武特·威提讪", "英文名": "Kunlavut VITIDSARN" }
]
```

**双打（男双 / 女双 / 混双）**

```json
[
  { "排名": 1, "所属": "KOR KOR", "球员": "金元浩 Kim Won Ho / 徐承宰 Seo Seung Jae" },
  { "排名": 7, "所属": "CHN FRA", "球员": "甲 Jia Name / 乙 Yi Name" }
]
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `排名` | 是 | 世界排名（数字），下拉列表按它排序并显示 |
| `所属` | 是 | BWF 三字母国家代码，不区分大小写（如 CHN、KOR、TPE、ENG）。双打写两个，用空格隔开（两人同国也可以只写一个）。没有对应国旗的代码只显示文字 |
| `球员` | 是 | 单打：中文名。双打：`甲中文 Jia English / 乙中文 Yi English`，两位选手之间用 ` / `（斜杠两侧各一个空格），每位选手“中文名 空格 英文名”（英文名可省略） |
| `英文名` | 否（仅单打） | 英文名，用于搜索，会统一成首字母大写 |
| 其他字段 | 否 | `升降`、`站数`、`积分` 等会被忽略，保留也没关系 |

注意：

- 外国选手的中文译名可以写成“法贾尔·阿尔菲安”，对阵图会按设置显示简称“阿尔菲安”。
- 文件里没有写明项目，所以导入前要先切到对应模式；单打文件导入到双打模式（或反过来）会报错提示。

## 已知限制

- 国旗用 flag-icons：中国台北显示的是台湾旗，不是奥运会旗。
- 没有做工程文件的保存/加载，只有浏览器本地自动保存。
