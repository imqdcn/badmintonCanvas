# 羽毛球对阵图编辑器 (badmintonCanvas)

纯前端 Web 应用，用来制作羽毛球赛事赛果对阵图，并导出 PNG 海报。

## 启动

```bash
npm install
npm run dev      # 开发，打开终端里提示的地址
npm test         # 运行测试
npm run build    # 类型检查 + 打包
```

## 在线使用

<https://imqdcn.github.io/badmintonCanvas/>

推送到 `main` 分支会通过 GitHub Actions 自动测试、打包并重新部署（见 `.github/workflows/deploy.yml`）。

## 怎么用

- **模式**：左侧面板切换 男单 / 女单 / 男双 / 女双 / 混双。每种模式的对阵数据独立保存。
- **规模**：8 / 16 / 32 / 64 强。切换会清空当前模式的对阵（有数据时会先确认）。
- **选手**：点击对阵图里的位置，弹窗里搜索（中文、拼音、首字母、英文）。
  - 默认只列当前模式的名单，切到“全部”可搜索其他四份名单。
  - 双打模式下可“手动组合双打”（从单打名单各挑一位）。
  - 名单里没有的选手用“新增选手/组合”，保存在浏览器本地。
- **晋级**：只有首轮（如 32 强）可以从名单里选人。16 强及以后的位置只能是上一轮这场比赛的两位选手之一：
  悬停在首轮位置上点 ▶，或点击后面轮次的位置，在弹窗里“选择这场比赛的晋级者”，可以随时改选另一位。
  “撤销晋级”会清空该位置。改了首轮已晋级的选手，后续轮次里的同一个人会被自动清除，并在左侧提示。
- **比分/备注/种子/轮空**：在弹窗里填写。种子在首轮设置，晋级后自动带到后面的轮次。比分显示在“该场比赛的获胜位置”下方（下一轮的位置）。
- **分区标签**（1/4区…）：直接点击文字修改。
- **头部**：左侧面板可换海报（可缩放、移动）、Logo、标题、高亮关键词、日期、社交图标、水印。
- **导出**：左侧面板底部选 1x/2x/3x，点“导出 PNG”。编辑用的按钮、轮廓线不会出现在图片里。
- 所有内容自动保存在浏览器 localStorage，刷新不丢。

## 目录说明（给不熟悉 React 的你）

```
src/
  domain/          纯 TypeScript，和 React 无关，可单独测试
    types.ts       数据类型（模式、选手、位置、对阵图）
    bracket.ts     对阵图的创建、修改、晋级、连带清除
    layout.ts      每个位置的像素坐标（还原效果图的核心）
    roster.ts      把源 JSON 解析成统一格式
    search.ts      名单搜索（含拼音）
    countries.ts   国家代码 -> 国旗/中文名
  providers/
    PlayerProvider.ts   名单数据源接口 + 内置 JSON 实现
  data/            5 份名单 JSON（BWF 2026 年第 45 周前 100 名）
  store.ts         Zustand 全局状态 + localStorage 持久化
  components/
    Header.tsx         海报头部
    Bracket.tsx        对阵图（绝对定位 + SVG 连线）
    SlotEditor.tsx     点击位置后的编辑弹窗
    ControlPanel.tsx   左侧控制面板
  export.ts        导出 PNG（html-to-image）
  styles.css
```

学习提示：

- 组件 = 返回界面的函数；`useStore(s => ...)` 读取全局状态，状态变了组件自动刷新。
- 对阵图数据是二维数组 `slots[轮][位置]`，第 0 轮是首轮，最后一轮只有 1 个位置（冠军）。
  下一轮第 `i` 个位置由上一轮第 `2i`、`2i+1` 两个位置产生。
- 想改外观先看 `styles.css`，想改逻辑先看 `domain/`。

## 更新名单

`src/data/*.json` 是从 BWF 排名导出的 5 份文件，字段：排名、所属、球员、英文名（单打）。
双打的“球员”字段格式为 `甲中文 Jia English / 乙中文 Yi English`，“所属”为 `KOR KOR`。
直接替换这些文件即可，格式不变就不用改代码。

以后想从 API 拉名单：新增一个实现 `PlayerProvider` 接口的对象，在 `getProvider()` 里切换。
注意 BWF 官网和中羽在线不能被浏览器直接访问（动态加载 / 拒绝自动请求），需要自己的后端做代理。

## 已知限制

- 国旗用 flag-icons：中国台北显示的是台湾旗，不是奥运会旗。
- `data/` 目录下的 `.xlsx` 和 `gemini-code-*.py` 是生成数据的中间产物，应用不使用。
- 没有做工程文件的保存/加载，只有浏览器本地自动保存。
